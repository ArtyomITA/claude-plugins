# Arcade games

Homebrew NES games, free and redistributable, for the arcade cabinet of the office. Each game is the work of its
author, under its own licence, unchanged; the `.txt` next to each `.nes` is the author's notice and licence as
published. Collected from [retrobrews/nes-games](https://github.com/retrobrews/nes-games), a collection of homebrew
games whose authors allow free distribution. The games marked NC may not be used commercially.

`games.json` lists every game with its size and SHA-256, so two friends with the same plugin have the same games and
their scores can be compared.
